# Menu product photography

The 20 menu images were generated with the built-in image generation tool on 23 October 2026.
They are photorealistic representative images based on the menu descriptions, not photographs
of drinks prepared by the shop. The house-special image uses a simple espresso-and-milk
presentation because its menu description does not specify a fixed recipe.

The website uses square 768-pixel WebP files under `assets/img/products/`, one per product slug.
Original generated images remain in the generation workspace. No stock-image service or remote
image dependency is used. The prior illustrations remain available in the source tree.

## Prompt set

Each image used this common prompt followed by its individual drink description:

> Use case: product-mockup. Create ONE square photorealistic cafe menu product photograph, not a drawing or 3D render. A single unbranded clear straight-sided 16-ounce takeaway cup, centered upright and completely visible including rim and base, filling about 75% of image height, on matte warm ivory tabletop against a seamless warm cream background. Camera at cup level slightly above the rim, 85mm product photography, soft daylight from upper left, subtle realistic shadow to right, crisp natural drink textures and fine condensation, warm neutral color grade. No people, hands, logos, labels, text, watermarks, decorative props, extra cups or artificial floating ingredients. Leave generous margin so square menu thumbnails do not crop cup.
